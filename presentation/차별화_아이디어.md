# 차별화 아이디어 — 남이 안 간 길

> 전제 두 가지
> 1. **전압·온도·자리 보정은 이미 다른 사람이 냈다.** 겹치면 안 된다.
> 2. **양산은 모든 셀이 동일 과정을 거친다.** 일부만 더 측정하거나 일부만 보관하는
>    방식은 불가. 적응형 측정·2단 선별은 애초에 후보가 아니다.
>
> 목표 두 가지
> - **A. SDM 측정시간 단축**
> - **B. 데이터 가공으로 선별력 향상**

---

## 왜 겹치는가 — 기존 접근의 공통 구조

전압 보정, 온도 보정, 자리 보정은 전부 같은 틀이다.

```
교란을 설명하는 변수를 사람이 지정한다 → 그 변수를 측정한다 → 빼거나 회귀한다
```

그래서 **변수 목록에 없는 교란은 못 지우고**, 온도계가 틀리거나 자리를 모르면
작동하지 않는다. 차별화는 이 틀 자체를 벗어나는 데서 나온다.

---

## ★★★ 제안 1. 값을 읽지 말고 **모양**을 읽는다

### 물리

15분 창 안에서 두 항의 **시간 모양이 다르다.**

| | 모양 | 근거 |
|---|---|---|
| **자가방전** | 거의 **직선 상승** | `I_sd·(1−exp(−t/τ))`, τ = 7.45시간. 15분은 τ의 3% |
| **열드리프트** | **올라갔다 감쇠** | `K·dT/dt`. 온도가 안정되면 스스로 사라진다 |

**실측 증거가 이미 있다.** 셀 140의 곡선이 `0 → −1.8 µA(15분) → −0.2 µA(30분)`로
**U자**였다. 다른 셀은 전부 단조 증가였다. 그 U자가 바로 감쇠하는 열 항이다.

### 방법

곡선을 두 기저로 분해한다. **직선 기저**와 **곡률 기저**(직선과 직교시킨 것).

```
I(t) = a·(직선) + b·(곡률)
        ↑           ↑
     자가방전      열드리프트
```

**`a`만 쓰면 열 항이 스스로 빠진다.**

### 차별점

- **보정 변수를 하나도 안 쓴다.** 온도계도, 자리도, 전압도, 층도.
  쓰는 것은 **전류 곡선 하나**.
- 온도계가 없거나 틀려도, 자리를 몰라도, **아직 이름 없는 교란이어도** 작동한다.
  모양만 다르면 갈린다.
- **측정을 바꾸지 않는다.** 모든 셀이 같은 15분을 받고, 읽는 법만 바뀐다.
  → 동일 과정 제약과 충돌하지 않는다.

### 근거를 데이터로 세우는 법 (이게 발표의 핵심 슬라이드)

> **직선 계수는 ΔOCV와 묶이고, 곡률 계수는 온도와 묶이는가?**

묶이면 두 성분이 서로 다른 물리를 담고 있다는 뜻이고, 분리가 성립한다.
`decompose.py [1]`이 이 표를 직접 낸다. **이 표 한 장이 논거 전체다.**

### 합성 데이터 검증 (실데이터 아님)

열 항을 실측 U자 모양으로 재현한 합성 데이터에서:

| 점수 | 상위1% | 상위5% | **최악셀 검사율** |
|---|---|---|---|
| 트레이 정규화 전류 | 25% | 38% | 38.37% |
| **직선 계수 (모양 분해)** | **62%** | **88%** | **11.84%** |
| 직선 − 곡률 | 50% | 88% | 14.86% |

**최악셀 검사율 38% → 12%.** 단, 이 합성 데이터는 제안이 가정하는 물리를
그대로 심어 만든 것이라 **"가정이 맞으면 작동한다"까지만** 증명한다.
가정이 맞다는 증거는 **셀 140의 실제 U자 곡선**이다.

## ★★ 제안 2. 전류가 아니라 **전하량**을 본다

양변을 적분하면 항의 성질이 갈린다.

```
I(t) = I_sd + K·dT/dt(t)
Q(t) = I_sd·t + K·[T(t) − T(0)]
        ~~~~~~~   ~~~~~~~~~~~~~~
      t에 비례해    온도 변화량에만 의존
      계속 자란다   → 유계(bounded)
```

온도는 결국 안정되므로 **열 항은 유한한 값에 갇히고**, 자가방전만 계속 자란다.
따라서 **Q(t)에 직선을 맞추면 기울기가 `I_sd`, 열 항은 절편으로 흡수**된다.

### 차별점
- 온도를 **재지 않아도** 열 항이 분리된다. 구조가 그렇게 되어 있다.
- 적분이 고주파 잡음을 눌러준다. 전압 분해능이 2 µV 눈금으로 요동하는 상황에 강하다.
- 제안 1과 같은 물리에서 나오지만 **수학적 경로가 다르다.** 서로 교차 검증이 된다.

## ★★ 제안 3. 불량을 찾지 말고 **양품에서 벗어난 정도**를 잰다

불량이 8개뿐이라 지도학습은 원리적 한계가 있다. 신뢰구간이 [53%, 98%]다.

대신 **양품 5,807개**로 정상 곡선의 범위를 만들고, 거기서 벗어난 정도를 점수로 쓴다.
라벨을 쓰지 않으므로 **불량 개수에 의존하지 않고**, 처음 보는 불량 유형에도 반응한다.

### 차별점
- 표본 부족 문제를 **회피**한다. 늘리는 게 아니라 안 쓰는 쪽으로 푼다.
- 한계 ④(불량 표본 확대가 최우선)에 대한 **다른 답**이 된다.

## ⚠ 제안 4. 함정 하나를 먼저 박아둔다 — 순진한 공통모드 제거는 실패한다

"같은 트레이 곡선들을 주성분분석해서 첫 성분을 빼면 공통 교란이 지워진다"는
자연스러운 발상이고, **틀렸다.**

모든 곡선의 모양이 비슷하면 **첫 성분은 교란이 아니라 그냥 "진폭"**이고,
**진폭이 곧 자가방전**이라 빼는 순간 신호가 지워진다.

합성 데이터 실측:
- PC1의 시간 모양 ≡ 평균 곡선 모양
- PC1 점수와 전류 끝값의 상관 **−0.999**
- 잔차 점수의 최악셀 검사율 **94.76%** (아무 보정 안 한 것보다 나쁨)

`decompose.py [1-b]`가 이 함정을 자동 검사한다.
**이건 발표에서 "우리는 이 함정을 피했다"로 쓸 수 있는 카드다.**
같은 길을 갈 사람이 반드시 밟는 지뢰이기 때문이다.

## 측정시간 단축(목표 A)에 대해

**이미 답이 나와 있다 — 5분.** 부록 12·15에서:
- 검출이 고정 5분과 고정 30분이 **완전히 동일**(62% / 88%)
- 근거는 "순위 안정화"가 아니라 **"검출 포화"**

제안 1·2는 여기에 **다른 방식으로** 기여한다. 모양 분해는 **곡선의 후반부가 필요**하므로
시간과 상충할 수 있다. `decompose.py [3]`의 시점별 표에서 직접 확인해야 한다.

> **측정시간과 선별력의 교환 곡선**을 그리는 것 자체가 발표거리다.
> "몇 분이면 되나"가 아니라 **"t분에서 얻을 수 있는 최대 선별력은 얼마인가"**.

## 아직 안 써본 데이터 — 요청 순위

| 순위 | 필요한 것 | 왜 |
|---|---|---|
| **1** | **1 Hz 원시 샘플** (지금은 1분 평균 26점) | 5분 = 300점. **잡음 구조 자체가 신호**일 수 있다. 내부 단락 셀은 전류 요동 특성이 다르다. 아무도 안 보는 축이다 |
| 2 | 분단위 온도 로그 `t_5min`…`t_30min` | 제안 1의 곡률 계수가 진짜 열 항인지 확정 |
| 3 | E 판정의 ΔOCV 외 기준 | 불량 8개가 전부 트레이 내 ΔOCV 1등이었다. 동어반복 여부 확정 필요 |

**1번이 압도적으로 중요하다.** 지금은 1분 평균으로 **잡음을 버리고** 있는데,
그 잡음에 정보가 있을 수 있다. 그리고 이건 다른 사람이 손대지 않은 축이다.

## 실행

```bash
python analysis/decompose.py "데이터.xlsx"
```

읽는 순서

1. **`[1]`의 판정** — 직선 계수가 ΔOCV 쪽에, 곡률 계수가 온도 쪽에 묶이는가.
   안 묶이면 제안 1은 이 데이터에서 성립하지 않는다. **먼저 이것부터.**
2. **`[1-b]`의 함정 검사** — 공통모드 제거를 시도하기 전에 반드시.
3. **`[2]`의 최악셀 검사율** — 모든 셀이 같은 시간을 측정하는 제약에서는
   이 값이 곧 **3일 보관을 없앨 수 있느냐**를 결정한다.
4. `[3]`의 시점별 표 — 전 셀 공통 측정시간을 하나 고른다.

## 정리 — 무엇이 달라지는가

| | 남이 간 길 | 이 길 |
|---|---|---|
| 무엇을 쓰나 | 온도·전압·자리 (측정 변수) | **전류 곡선 하나** |
| 어떻게 지우나 | 변수를 재서 뺀다 | **모양으로 가른다** |
| 안 될 때 | 변수가 목록에 없으면 실패 | 모양만 다르면 작동 |
| 무엇을 읽나 | 전류 **값** | 전류의 **기울기·곡률·전하량** |
| 라벨 | 불량 8개로 학습 | **양품 5,807개로 범위 학습** |
| 측정 | — | **모든 셀 동일. 읽는 법만 바꾼다** |
