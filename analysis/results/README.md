# 실행 결과 자동 저장

스크립트를 돌리면 화면 출력이 그대로 여기에 저장됩니다.

```
<스크립트>_<입력파일>_<날짜_시각>.txt
```

파일 맨 위에 실행 시각·입력 파일·명령이 붙습니다. 옵션 없이도 항상 저장됩니다.

| 옵션 | 뜻 |
|---|---|
| `--save=경로` | 저장 위치를 직접 지정 |
| `--no-save` | 저장하지 않음 |

이 폴더는 git 에 포함됩니다. 결과를 커밋해서 푸시하면 그대로 공유됩니다.
용량이 커지면 오래된 `.txt` 를 지우십시오. 지워도 분석에 영향은 없습니다.
(이 README 가 `.md` 인 것은 `rm *.txt` 로 정리할 때 같이 지워지지 않게 하기 위함입니다.)
